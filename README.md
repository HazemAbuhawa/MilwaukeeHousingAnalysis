milwaukee Housing Price Predictor

Objective: Developed a machine learning model to predict property prices based on 2025 market data.

Key Achievements:

Data Engineering: Cleaned and filtered outliers (removed non-representative multi-million dollar transactions).

Insights: Discovered that District 3 carries a price premium regardless of square footage.

Model: Achieved 90% accuracy using Linear Regression with Multi-feature encoding.

Tools: Python, Pandas, Scikit-learn, Seaborn.
